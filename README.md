# 奶龙桌宠

一个使用本地视频驱动的 Windows 桌面宠物。

## 使用

1. 确保电脑已安装 Python 3.11 或更高版本。
2. 双击 `start.bat`。首次启动会在项目内创建 `.venv` 并安装依赖。

## 操作

- 单击：播放前 1.7 秒“斜眼”动画一次，在笑的动作前结束。
- 双击：播放视频前 8 秒的“斜眼 + 大笑”动画一次。
- 左键拖动：移动桌宠位置，靠近显示器工作区边缘时自动吸附。
- Ctrl + 左键左右拖动：连续改变大小。
- 鼠标滚轮：每次放大或缩小 12px，允许范围为 60–720px。
- 右键菜单：小/中/大尺寸预设、声音开关、音量、闲置动作、边缘吸附、显示器选择、开机自启动、隐藏、退出。
- 托盘图标：双击显示桌宠，右键可显示、隐藏、播放大笑、切换声音或退出。

位置、尺寸、声音、音量、闲置动作和吸附偏好保存在项目内 `settings.json`，重启自动恢复。
内部继续以 720px 去背后下采样，避免紫边。
声音使用视频前 8 秒原声；视频没有音轨时保持静音，可通过右键“声音状态”查看。
闲置动作默认关闭；开启后，空闲约 30 秒会随机播放素材中的眨眼或侧看片段，不会大笑。
开机自启动默认关闭；仅在右键开关开启后写入当前用户的 Windows 启动项，关闭即可移除。
支持负坐标显示器，可拖动跨屏，或通过右键菜单切换显示器；显示器断开后重新显示会回到可见工作区。

动画播放结束后会自动回到第一帧。
如果启动失败，项目目录中会生成 `desktop_pet_error.log`。

## 可选参数

```powershell
.\.venv\Scripts\python.exe app.py --width 720 --display-width 180 --chroma-tolerance 55
```

- `--width`：内部渲染宽度，默认 720 像素。
- `--display-width`：桌面实际显示宽度，默认 180 像素。
- `--chroma-tolerance`：去除脚下及四周灰白背景的饱和度阈值，默认 55。
