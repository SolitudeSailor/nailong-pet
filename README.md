# 奶龙桌宠

一只会动、会发声的 Windows 桌面奶龙。可以拖动、缩放、隐藏，还能设置开机自动出现。

支持 Windows 10/11。

## 主要功能

- 单击或双击奶龙播放不同动画
- 播放动画原声，可调音量或静音
- 自由拖动、缩放，并自动吸附屏幕边缘
- 支持多显示器
- 可开启闲置小动作和开机自启动
- 自动记住位置、大小和设置

## 安装使用

### 下载安装包（推荐）

1. 打开 [Releases](https://github.com/SolitudeSailor/Nailong-Desktop-Pet/releases) 页面。
2. 下载最新的 `奶龙桌宠-安装程序-版本号-x64.exe`。
3. 双击安装，完成后即可启动。

安装不需要管理员权限。

### 从源码运行

1. 安装 64 位 Python 3.11 或更高版本。
2. 下载或克隆本项目。
3. 双击 `start.bat`。

首次启动会自动创建运行环境并安装依赖，需要保持网络连接。

## 怎么操作

| 操作 | 效果 |
|---|---|
| 单击奶龙 | 播放侧看动画 |
| 双击奶龙 | 播放完整动画和声音 |
| 按住左键拖动 | 移动奶龙 |
| 滚动鼠标滚轮 | 放大或缩小 |
| 按住 Ctrl，再用左键左右拖动 | 连续调整大小 |
| 右键奶龙 | 打开设置菜单 |
| 双击托盘图标 | 重新显示奶龙 |

在右键菜单中可以调整尺寸、音量、显示器、闲置动作、边缘吸附和开机自启动。

## 常见问题

### 双击 `start.bat` 后没有反应

请确认已安装 Python 3.11 或更高版本，并勾选了“将 Python 添加到 PATH”。也可以查看项目目录中的 `desktop_pet_error.log`。

### 没有声音

右键奶龙，确认“播放视频原声”已开启，并检查系统音量。

### 奶龙不见了

双击任务栏右下角的托盘图标，或右键托盘图标选择“显示”。

